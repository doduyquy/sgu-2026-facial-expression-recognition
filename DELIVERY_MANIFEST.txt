📊 ARCHITECTURE SUMMARY
════════════════════════════════════════════════════════════════════════════

Input (48x48 grayscale FER2013 image)
    ↓
[1] CNN Backbone
    • 3 Conv blocks with BatchNorm + ReLU + MaxPool
    • Output: (B, 128, 6, 6) feature map
    • Purpose: Feature extraction
    ↓
[2] Region Attention Module
    • Generate K=3 attention maps via 1x1 Conv
    • Spatial softmax over 6x6 grid
    • Weighted pooling: region[k] = Σ(att[k] * feat)
    • Output: (B, 3, 128) region features
    • Purpose: Preserve spatial structure, find discriminative regions
    ↓
[3] Graph Attention Module
    • Treat 3 regions as nodes in fully-connected graph
    • Multi-head attention (4 heads)
    • Learn edge weights and aggregate features
    • 2 layers of graph attention
    • Output: (B, 3, 128) updated region features
    • Purpose: Model inter-region relationships
    ↓
[4] Motif Module (Parallel to Graph)
    • 7 learnable emotion prototypes
    • Compute cosine similarity to each emotion
    • Output: (B, 3, 7) region-emotion scores
    • Purpose: Match learned patterns to emotions
    ↓
[5] Fusion & Classification
    • Average graph features: (B, 128)
    • Concatenate with motif features: (B, 21)
    • MLP: 149 → 256 → 128 → 7
    • Output: (B, 7) emotion logits
    • Purpose: Final classification
    ↓
Output (7 emotion probabilities via softmax)
