✅ FIX 6.4: PROTOTYPE ORTHOGONAL REGULARIZATION
=====================================================================

📍 File: src/training/losses.py (NEW function)

Added: prototype_orthogonal_loss(prototypes)

Purpose: Prevent motif prototypes from collapsing (becoming identical)

How it works:
  1. Normalize prototypes: p_norm = F.normalize(p)
  2. Compute similarity: sim = p_norm @ p_norm.T
  3. Penalize off-diagonal: loss = ((sim - eye)²).mean()

Configuration: prototype_orthogonal_weight: 0.1

🚀 Impact: Prevents prototype collapse → stable learning
✅ Test: PASSED - Verified orthogonal loss works
         - Random prototypes loss: 0.0009
         - Orthogonal prototypes loss: 0.0000 ✓
